# CVSMS Android application — MIT App Inventor

We built our Android monitoring interface in **MIT App Inventor** and connected the application to the ThingSpeak data displayed during the capstone demonstration.

I have retained the [Android interface screenshot](../assets/project-images/05-iot-and-android/android-app-screen.png), [block-programming screenshot](../assets/project-images/05-iot-and-android/app-inventor-blocks.png) and [ThingSpeak dashboard](../assets/project-images/05-iot-and-android/thingspeak-dashboard.png).
