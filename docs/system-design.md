# System design and hardware
The original capstone book (June 2024), Chapter 4, documents the MR60BHA1 radar module, ESP8266 NodeMCU, lithium-ion power supply, TP4056 charging/boost converter, 20×4 I2C LCD, 3D-printed casing, ThingSpeak, and MIT App Inventor. Chapter 3 covers the system block diagram and IoMT workflow. The architecture in the README is a redrawn conceptual summary, not a recovered original figure or verified pin-level wiring schematic.

The sensor outputs physiological estimates for embedded display and cloud communication. Verify sensor firmware, serial protocol, pin assignments, electrical ratings, and the final device revision against original lab files before attempting hardware reproduction.
