## Before public release
- [ ] Confirm teammate permission for redistribution of original source and project materials.
- [ ] Confirm supervisor/institution rules for sharing capstone diagrams and figures.
- [ ] Obtain authentic figure images and label them by book figure number.
- [ ] Obtain the `.aia` file and real application screenshots if available.
- [ ] Check the firmware against actual library versions and board UART constraints.
- [ ] Rotate historical Wi-Fi and ThingSpeak credentials if they might still be active.
- [ ] Verify any grant name, award documents and exact paper citation.
- [ ] Remove any personally identifiable human-subject data.

**This repository is a detailed, clickable engineering presentation of the project, not a verbatim redistribution of the copyrighted thesis book.**
